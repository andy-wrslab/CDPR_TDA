SOURCE NAMES AND ANALYSIS METADATA CHANGES

Public source filenames and MATLAB entry points no longer carry revision
suffixes. The old/current mapping and original/current SHA-256 hashes are
recorded in provenance/SOURCE_MANIFEST.csv. That file also records the previous
reviewer-package hashes and non-comment-line hashes before and after renaming.

The original measured numerical statements, solver settings and timer boundaries
are preserved after applying this identifier mapping. No compatibility wrappers
or extra calls were inserted into a measured path. Diagnostic namespaces and
source snapshot filenames follow the new function names. The harness default
directory prefix and descriptive capture/affinity messages were also simplified.
Reported timings remain the original observations; new test timings are separate.

Historical source_snapshot filenames in the norm-analysis input checklist and
FULL_DATA_INVENTORY.csv are intentionally retained. They identify immutable saved
inputs, not the current public functions. The replay guards still read solver
names from each input manifest, so historical captures remain readable.

Existing presentation changes, before this rename:
- Numerical-function edits were full-line comments and blank lines only.
- Summary source-snapshot list omitted the unused historical plot helper.
  The wrapper still disables plotting; no plot helper is distributed.
- Norm-analysis relative paths were resolved against MATLAB's Current Folder.
  All norm calculations and acceptance masks were unchanged.
The renamed harness help example explicitly disables the omitted plotting path.
